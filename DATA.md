# Data index: where everything is

> **DEMO ONLY.** Public open-source research data; nothing here is a diagnosis. Agents: this is the single place that lists every dataset and where it lives. Nothing in the app is a flat picture. Every case is a **full 3D CT volume** (every slice), stored as raw voxels and sliced live by the Metal renderer.

## In the app (branch `main` / `demo/addenda-and-pipeline`, folder `App/Cases/`)

Each case is one folder with five files, in the format of PRD addendum A4:
- `ct.raw`: int16 HU, x fastest, RAS
- `labels.raw`: uint8 label ids
- `meta.json`, `layers.json`, `findings.json`
- optional: `analysis.json` (Hugging Face model description) and `detection.json` (hemorrhage detector)

| Case | Source | Volume | Link |
|---|---|---|---|
| `head` | CQ500-CT-243 + Seg-CQ500 subdural mask | 225 × 256 × 216 @ 0.8 mm | https://zenodo.org/records/8063221 (Seg-CQ500, CC BY 4.0), http://headctstudy.qure.ai/dataset (CQ500, CC BY-NC-SA 4.0) |
| `body` | NLM Visible Human Male, normal CT | 239 × 169 × 487 @ 2.0 mm | https://www.nlm.nih.gov/research/visible/getting_data.html, via NCI IDC collection `nlm_visible_human_project` (https://portal.imaging.datacommons.cancer.gov/) |
| `pants8205` (being added) | JHU BodyMaps **PanTS_00008205**, the same case as https://bodymaps.wse.jhu.edu/case/8205 | full-resolution slices | https://huggingface.co/datasets/BodyMaps/iPanTSMini (`image_only/PanTS_00008205/ct.nii.gz`, `mask_only/PanTS_00008205/`), CC BY-NC-SA 4.0 |
| `sun`, `circuit` | Synthetic (generated by `data/synth/make_synth.py`) | 80³ and 96 × 96 × 32 | this repo |

Loader and verification: `App/Core/CaseBundle.swift`, `data/verify.py`, `scripts/core_selftest.sh`.

## Raw downloads, intermediates and model weights (branch `data/assets`)

https://github.com/machmoon/Generalizable/tree/data/assets

Everything is chunked into parts under 95 MB. Restore with:

```
git fetch origin data/assets
git worktree add ../gz-data data/assets
../gz-data/unpack.sh <asset> <dest>
```

Its `README.md` lists every asset:
- the Visible Human DICOM
- the body and head NIfTI volumes
- the Seg-CQ500 bleed mask
- the TotalSegmentator masks and weights
- the pre-cleanup bundles
